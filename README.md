

\# Hello World CI Pipeline



\## Project Description

A simple GitHub Actions project demonstrating a CI pipeline.



\## Files

\- hello.sh: Prints Hello, world!

\- .github/workflows/ci.yaml: Defines the workflow.



\## Jobs

1\. Build: Prints a build message.

2\. Test: Runs after Build.

3\. Deploy: Runs after Test.



\## Trigger

The workflow runs on a pull request event.



\## Tools Used

\- Git

\- GitHub

\- GitHub Actions

\- Shell scripting

\- YAML
